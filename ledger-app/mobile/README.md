# 私人账本手机客户端

Flutter 客户端，包含 Android 和 iOS 工程。手机保存流水、报表缓存和待同步修改，主账本由 Windows 上的 FastAPI 服务保存。

当前手机端源码为 **0.4.1+9**。总览和统计按本机流水实时计算，离线新增和修改保存后立即生效。电脑端可继续使用 0.4.0。导入审核和 CSV 导出仍由电脑端处理。

## 安装 APK

客户端要求 Android 7.0（API 24）或更新版本。APK 只包含手机应用；要导入账单和进行首次同步，还需要先启动 Windows 后端。

1. 将 [ARM64 手机 APK](../../ledger-0.4.1-arm64-v8a-release.apk) 通过 USB 或自己使用的文件传输方式复制到手机。
2. 在手机的文件管理器中打开 APK。若系统询问安装权限，只需给当前文件管理器开启“允许安装未知应用”，然后继续安装。
3. 打开“私有账本”，按下文“首次连接”配置服务器。首次连接前尚无流水，离线查看需要先成功同步一次。
4. 更新时打开新版 APK 并覆盖安装，尽量保留原应用数据。若系统提示签名不一致，先保留当前应用并检查安装包；卸载会清除本机尚未同步的修改。

0.4.1 APK 已核验版本、架构及 v2 签名。ARM64 手机包为 18.14 MiB，另有 [x86_64 模拟器包](../../ledger-0.4.1-x86_64-release.apk)，19.55 MiB。可覆盖安装同签名旧版。150 项 Flutter 测试通过，本版尚未做真机安装验证。

## 从源码构建

本项目使用 Flutter 3.47.5 / Dart 3.13.4 进行源码检查和测试。开发时安装 Flutter stable、Android Studio 和 Android SDK，并将 Flutter 的 `bin` 加入 PATH。在本目录运行：

```powershell
flutter doctor
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run
```

`pubspec.lock` 固定已验证的 Dart 依赖版本，包源为 pub.dev。Android 工程使用 Flutter 默认 SDK 配置（当前最低 Android API 24）。本机双击 `outputs/build-ledger-release.cmd` 会先验证再生成分架构 Release 包；等价构建命令为 `flutter build apk --release --split-per-abi --target-platform=android-arm64,android-x64`。如需开发调试，使用 `outputs/build-ledger-apk.cmd -BuildMode Debug`。分包 versionCode 会加上架构前缀，后续应继续同架构递增覆盖升级，不用卸载来绕过低版本限制。正式发行前需要配置自己的应用标识和签名；目前 release 仍使用 Flutter 模板的开发签名。

iOS 需要在 macOS 上通过 Xcode 构建并配置签名。已生成 iOS 工程，Windows 环境尚未进行 iOS 编译与真机验证。

## 首次连接

1. 双击项目 `outputs/start-ledger-server.cmd` 打开电脑端，确认局域网网卡，点击“启动服务”，等待“服务就绪”。窗口会保存固定令牌供以后启动复用。
2. 点击电脑端“复制地址”，在手机填写服务器**根地址**，例如 `http://192.168.1.20:8000`；不要加 `/health`、`/docs` 或 `/api/v1`。使用 HTTP 时按提示确认网络可信。点击“先检查网络（无需令牌）”，看到网络连通后再继续。手机上的 `127.0.0.1` 指向手机自身，不能填作电脑地址。
3. 在电脑端点击“复制连接令牌”，将相同值粘贴到手机，点击“连接并同步账本”。界面会显示正在检查网络、验证令牌或保存本地副本；失败时保留输入并显示处理步骤。换网络后电脑 IP 可能改变，需要重新填写当前地址。
4. 点击顶部“导入账单”，选择 CSV 或包含一个 CSV 的 ZIP，核对预览后确认；“我的”可创建自动分类规则及修改红包默认统计口径。导入需要能连接后端。
5. 外出使用时，电脑和手机需接入同一个私人 VPN，后端监听电脑的 VPN IPv4，应用填写该地址；已配置 HTTPS 的服务也可直接填写 HTTPS 根地址。

Android Studio 官方模拟器访问 Windows 主机通常使用 `http://10.0.2.2:8000`。MuMu 等第三方模拟器的主机访问方式可能不同，应以模拟器实际网络配置为准；不能直接假设都支持这个地址。

目前尚无支付宝、微信真实脱敏样本，平台格式还需要校准。导入失败时会保留现有账本；后端目录中的通用 CSV 模板只有表头，需要先补充测试流水再导入。

## 连接问题排查

| 现象 | 检查方法 |
| --- | --- |
| Windows 本机也打不开 `/health` | 查看启动服务的 PowerShell 是否仍在运行、有无报错，确认端口是 8000。 |
| 电脑能打开、手机打不开 | 确认后端已监听电脑的局域网或 VPN 地址；检查手机与电脑的网络、Windows 防火墙，以及 Wi-Fi 是否隔离设备。 |
| 返回 401 | 核对手机与后端的令牌。重新启动后端时仍须设置原来的 `LEDGER_API_TOKEN`。 |
| 应用拒绝服务器地址 | 使用根地址；HTTP 只接受私有 IPv4、VPN IPv4 或本机开发地址，公网服务使用 HTTPS。 |
| 电脑上新增的流水还没在手机显示 | 点击“同步账单”。同步到手机的流水会自动计入手机统计。 |

## 离线和统计

- 流水详情支持分类、多个标签、备注、是否计入报表，以及退款关联原消费。保存先写入手机 SQLite，关闭应用后待同步修改仍保留。
- 应用打开、回到前台、保存修改时会尝试同步；处于前台时每 60 秒重试，也可点右上角手动同步。系统将应用挂起或关闭时不保证后台同步，重新打开后继续。
- 多设备同时修改同一交易会显示冲突，可选保留本机修改或采用服务器版本。上传前先检查账本身份和服务器版本；服务器被替换或回退时暂停同步，保留手机数据。
- 总览、月报和年报根据手机流水即时计算。离线新增、修改、排除或关联退款后，待同步的流水立即计入统计，切换月份和年份也可离线。
- 月报可导出当月或全年 CSV。更新后的后端在脱敏导出中去掉商户、描述、外部交易号、标签和备注，分类改为别名、记录标识每次替换，日期和金额仍保留。CSV 由用户选择保存位置，再自行交给外部工具分析；脱敏不等于匿名，不同导出之间不能按别名或临时 ID 关联。
- 红包默认排除，可在设置修改；转账默认排除，可逐笔或通过导入规则纳入。退款需要关联原消费，随后冲减原消费月份。

## 数据保存

本地数据库位于应用私有的 `Application Support/LedgerMobile` 目录，令牌位于系统安全存储。Android 已禁用应用云备份和设备迁移，iOS 的账本目录标记为不参与备份，令牌使用本机 Keychain 存储；这些平台配置还需要真机确认。

换机时连接原 Windows 服务即可重新下载账本。卸载手机应用前，先确认所有离线修改已同步；Windows 主数据库需要单独备份。
