# 私人账本（第一版）

这是一套运行在自己设备上的记账软件：Windows 电脑保存主账本，手机保存可离线使用的副本。第一版通过导入支付宝、微信导出的账单文件获取流水；自动读取个人账户的官方接口暂未接入。

2026-10-28 已清理早期 APK、编译中间产物、下载归档和历史测试临时文件。当前保留 0.4.0 及上一版 0.3.4 的 ARM64/x86_64 APK和校验文件；[清理记录](../项目清理记录-2026-10-28.md)列出范围与限制。后续测试/打包会重新生成缓存，必要时重新下载可再生依赖，不影响当前源码和已安装工具。

## 技术栈及原因

```text
支付宝/微信导出文件 → FastAPI 导入与规则 → Windows SQLite 主账本
                                              ↕ REST/JSON + 修订号
                               Flutter Android/iOS → 手机 SQLite + 待同步队列
```

- **Flutter / Dart**：Android 和将来的 iPhone 共用大部分界面与离线逻辑，换平台时无需重写整套客户端。
- **FastAPI / Python**：后端与移动界面用明确的 HTTP API 分开；Python 便于处理不同账单格式和统计规则，并可在 Windows 上运行。
- **SQLite**：个人账本数据量适中，主机和手机都可以使用本地文件数据库，无需另装数据库服务。手机将离线编辑记录到持久化队列，服务端用版本号检测冲突。
- **私有 VPN 或 HTTPS**：Windows 电脑常开时，手机离家后通过受保护的网络访问自有主机。手机根据本机流水即时计算月报和年报，待同步的新增和修改也计入。

这是“前后端分离 + 本地离线缓存”的结构。完整账本以 Windows 电脑为准，手机保留同步副本；两台手机连接同一服务后可自动同步。

## 目录与运行

本机双击 `outputs/start-ledger-server.cmd` 打开电脑端，点击“启动服务”等待“服务就绪”。手机填写窗口当前地址，先点“先检查网络（无需令牌）”，再填写电脑端的连接令牌完成同步。局域网超时请看[连接排查与隐私说明](CONNECTION-PRIVACY.md)；详细只读诊断入口为 `outputs/check-ledger-connection.cmd`。

- [`server/`](server/)：FastAPI 后端、导入器、规则、统计和测试。Windows 启动步骤见 [`server/README.md`](server/README.md)。
- [`mobile/`](mobile/)：Flutter 应用、Android/iOS 工程和测试。安装与构建步骤见 [`mobile/README.md`](mobile/README.md)。
- [`server/app/importers/generic_template.csv`](server/app/importers/generic_template.csv)：通用 CSV 表头示例；填入测试流水后可用于试导入。

初次使用顺序：先按后端说明在 Windows 启动服务并保存令牌，再按客户端说明安装 APK、填写服务器根地址和令牌，最后导入一份测试 CSV。APK 生成情况以本文件的验证记录为准；不需要在手机安装 Flutter 或 Python。

需要定期备份 Windows 主数据库。CSV 适合分析和分享，完整换机恢复还需要保留主数据库中的原始流水、人工修改、规则及设置。

## 目前需要验证的地方

你目前还没有支付宝、微信的脱敏导出样本。导入器支持通用 CSV 和常见中文表头，但两个平台各版本的真实字段、退款关联方式和特殊交易状态尚未经过样本校验。拿到样本后，应先在预览里核对笔数、金额、收支方向和排除结果，再补充专用格式适配与自动退款关联。现在未关联的退款需要在流水详情中手动关联原消费。
