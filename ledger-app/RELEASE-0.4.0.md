# 0.4.0：手动记账、完整编辑、导入审核与同步控制

## 更新与使用

1. 电脑端先停止服务，再重新启动，确保加载新后端。
2. 手机覆盖安装 `ledger-0.4.0-arm64-v8a-release.apk`，同一签名可保留数据。新接口需要与更新后的电脑端配合。
3. 主界面右下角或流水页点击“记一笔”，输入支出/收入、金额、商户/对象、说明、日期、分类、标签及备注，保存。首次需先连接账本建立身份；之后断网也可记账，联网后同步。
4. 点开一笔流水，在详情中修改金额、日期、商户、说明、收支方向、分类、标签、备注等，再保存。导入原始值仍在原始字段中留存；重复导入按原交易标识去重，不覆盖人工修正。
5. “我的”可开关手机与电脑的自动同步，也可点“立即同步”。开启时在应用前台每60秒、回到前台及保存新增/修改时尝试；后台受系统限制，不能保证持续执行。电脑断网时保留待同步项。
6. 文件导入后每页50笔，可翻页查看全部流水并识别重复项；勾选已审核，再点击确认导入，最终弹窗确认后才入账。取消或尚未确认的预览不计入收支。此版审核按整批确认，不提供导入前逐笔勾选排除。

## 微信、支付宝 API 结论

目前核实的公开官方账单 API 用于商户及其授权服务商的对账，并不能直接取得普通个人账户全部消费流水。此版没有接入个人支付账户自动取数，也不要求支付密码、Cookie、验证码或商户私钥。个人账单仍通过官方导出文件导入；手机与电脑自动同步指的是同步本应用账本。

- 微信商户官方账单说明：https://pay.wechatpay.cn/doc/v3/merchant/4013071218
- 支付宝官方账单接口：https://developer.alibaba.com/docs/api.htm?apiId=1054&docType=4

## 数据正确性与验证

- 手动新增采用手机生成的固定交易ID和操作ID，先在本地事务写入交易和待同步队列，服务端幂等创建。
- 测试覆盖断网新增、关闭重开、创建响应丢失后重试、创建后离线编辑，保证重试不重复入账。
- 编辑继续使用预期版本、冲突保护与操作幂等；金额使用整数分，时间需带时区并按北京时间统计。
- 已关联退款的原支出不能直接改为收入；需先解除关联，防止破坏退款统计。
- 手机完整149项测试通过，分析无问题；后端81项测试和10个子测试通过。合成数据测试包括审核分页、确认前不提交、修改后跨月报表、原始数据保留和创建鉴权。
- 320像素手动输入表单已测试并实渲染检查，未将用户真实流水用于测试夹具。
- ARM64 / x86_64 Release 构建及 v2 签名验证通过，versionCode为2008/4008。手机原生安装和跨设备新增/编辑的最终体验尚待实际试用，当前未连接设备。
